# TicTacToe
> Desarrollado por Alejandro del Valle alias AlejAndroidDeVV
> Versión Actual: 0.1 (En desarrollo)

Tica Tac Toe es un pequeño proyecto personal que recrea el mítico juego TicTacToe en HTMl, CSS, y JS puro.
Está creado con el fin de practicar lógica en el lenguaje JS y de entretenerme elaborándolo.
